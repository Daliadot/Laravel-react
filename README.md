# 💞 care.ly°

O **care.ly°** é um aplicativo mobile que conecta voluntários e iniciativas de ajuda comunitária, trazendo um design amigável e funcional. Aqui, quem precisa de apoio encontra quem quer ajudar — tudo com empatia, organização e muito carinho!

## 📱 Funcionalidades

- Cadastro e login de voluntários
- Cadastro de iniciativas de apoio (ONGs, projetos locais etc)
- Feed visual das iniciativas cadastradas
- Área de perfil com histórico de participações

## 💡 Inspiração

Inspirado na ideia de facilitar boas ações como se fosse pedir comida — rápido, simples e acessível — o care.ly° nasceu para transformar o voluntariado em algo cotidiano, fácil e encantador.

## 🔧 Tecnologias

- **React Native + Expo** – Interface mobile
- **Laravel** – Backend e API
- **MySQL** – Banco de dados relacional

- **Docker** (opcional) – Para ambientes padronizados
